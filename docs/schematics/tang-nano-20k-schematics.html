Logic loaded onto the board's GW2AR-18, drawn as signal flow. One tab per project in the tang-nano-20k repo.

The logic in projects/hello/hello.v: a free-running counter that drives the six LEDs, and a UART transmitter that sends a greeting to the PC once a second.

The design is loaded into SRAM only. Unplugging the board brings back the LiteX design stored in flash.

The logic in projects/stoplight/stoplight.v: a two-way intersection on the six on-board LEDs. A second timer feeds a phase counter, which steps a six-state register that decides which lamps are lit.

States

statenorth–southeast–westseconds
0 NS greengreenred5
1 NS yellowyellowred2
2 all redredred1
3 EW greenredgreen5
4 EW yellowredyellow2
5 all redredred1

One full cycle is 16 seconds. State 5 is also the power-up state, so the board starts all red.

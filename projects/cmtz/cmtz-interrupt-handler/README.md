# cmtz-interrupt-handler

Verified interrupt handler with catalytic register restoration.

The datapath is generated by the Verilog backend of the Cook-Mertz compiler from `09_interrupt_handler.cmtz`:

```
-- 09_interrupt_handler.cmtz
--
-- Verified interrupt handler with catalytic register restoration.
--
-- Scenario: a main computation is running when an interrupt fires.
-- The handler must compute something useful (a phasor power measurement)
-- using workspace registers, then provably restore them to their pre-
-- interrupt values so the main computation can resume safely.
--
-- This is the feature with no analogue in other languages: the compiler
-- statically verifies that the listed registers are not clobbered.
--
-- Architecture:
--   Main:  embed_0 = ω^5 (some ongoing computation state)
--   IRQ:   cembed two phasors, superpose, measure power
--          must not destroy embed_0
--
-- `interrupt { } restoring (...)` is the strict variant — the catalytic
-- verifier proves the listed registers come back clean.  If any inner
-- node clobbers a listed register, compilation fails.

field(17, 19);
roots(17) as omega;

-- ── Main computation state (must survive the interrupt) ──────────

embed(0, 5);                -- embed_0 = ω^5 = 14  (caller's register)

-- ── Interrupt handler: compute phasor power without clobbering ───

interrupt {
    -- Handler does its own work using fresh registers.
    -- embed_0 is listed as restoring — the verifier will reject
    -- any inner node that writes to embed_0.
    embed(1, 0);            -- embed_1 = ω^0 = 1  (handler workspace)
    embed(2, 3);            -- embed_2 = ω^3 = 10 (handler workspace)

    -- Superpose handler signals
    add(embed_1, embed_2) as irq_sum;   -- 1 + 10 = 11

    -- Measure a result from the handler
    measure(irq_sum, mod_p) as irq_result;  -- 11
} restoring (embed_0);

-- ── Main computation continues: embed_0 is still ω^5 ────────────

rotate(embed_0, embed_0, 3);                -- ω^5 · ω^3 = ω^8 = 16
measure(rot_embed_0_embed_0, mod_p) as main_result;    -- expect 16

-- Both results are valid:
--   irq_result  = 11  (handler's work)
--   main_result = 16  (main thread, embed_0 was preserved)
```

The program's literal embeds are replaced by input ports, so the datapath computes the same graph for any values in 0 to 16 instead of the constants in the source. It has 1 pipeline stage, one result per clock, and no `%` operators: reductions are unrolled conditional subtracts.

## Ports

| Port | Bits | Carried as |
|---|---|---|
| `in_embed_0` | 5 | request byte 0 |
| `in_embed_1` | 5 | request byte 1 |
| `in_embed_2` | 5 | request byte 2 |
| `out_irq_result` | 5 | reply byte 0 |
| `out_main_result` | 5 | reply byte 1 |

## UART protocol

115200 8N1 on the on-board USB bridge. Send 3 bytes (each 0 to 16), read 2 bytes back. A complex port is two bytes, real part first. If any request byte is 17 or more, every reply byte is `0xFF`. If a request stalls partway for 250 ms, the bytes received so far are dropped. Bytes sent while a reply is going out are ignored, so read the whole reply before sending the next request.

Example: `08 10 0F` replies `0E 0C`.

LEDs (active low): `leds[4:0]` show the low bits of the first reply byte, `leds[5]` lights after an error reply.

## Files

| File | What |
|---|---|
| `cmtz_interrupt_handler_uart.v` | Top module `cmtz_interrupt_handler_uart`: UART receiver and transmitter and a control state machine around the datapath. Generated. |
| `cmtz_interrupt_handler.v` | The datapath. Generated. |
| `cmtz_interrupt_handler_tb.v` | Datapath testbench with 66 vectors, expected values from the compiler's Python reference. Generated. |
| `cmtz_interrupt_handler_uart_tb.v` | Whole-design testbench: bit-bangs the UART protocol for every vector, then checks the out-of-range reply and the resync timeout. Generated. |
| `pins.cst` | `clk` pin 4, `tx` pin 69, `rx` pin 70, LEDs pins 15 to 20 |
| `apio.ini` | Board and top module |

Regenerate with `examples/fpga/build_projects.py` in the Cook-Mertz repo rather than editing the generated files.

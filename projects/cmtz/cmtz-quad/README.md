# cmtz-quad

4 cmtz-core lanes for F_17 (q = 19) in one bitstream, behind one UART
(RFC-003, `rfcs/RFC-003-catalytic-multicore.md` of the Cook-Mertz repo).
Each lane is an unmodified `cmtz_core`: its own program memory, data memory, registers and control. The lanes share the clock and nothing else.
Every lane runs any cmtz-core program; the single-core tools (`core_run.py`)
refuse this bitstream, since it answers `I` with `CMTM` instead of `CMTC`.

## UART protocol (CMTM)

115200 8N1. As cmtz-core's protocol (`cmtz/isa/host.py`), acting on the
selected lane, plus:

| Byte | Meaning |
|---|---|
| `I` | 25-byte info: `CMTM`, protocol version, lanes, leases, ISA version, p, q, memory sizes, hash, selected lane, its program length and crc32 |
| `L n` | select lane n |
| `B mask` | start every lane in the mask on the same clock |
| `Q` | 28-byte status: cmtz-core's 16 bytes, then the first running cycle, the first cycle after the run, and the cycles stalled on a lease (free-running 27 MHz counter) |


Full description: the docstring of `cmtz/isa/mlane_host.py`.

## Files

| File | What |
|---|---|
| `cmtz_core.v` | One lane. Generated by `emit_core`, byte-identical to cmtz-core's. |
| `cmtz_mlane.v` | 4 lanes, cycle stamps. Generated. |
| `cmtz_mlane_uart.v` | Top module `cmtz_mlane_uart`. Generated. |
| `cmtz_mlane_tb.v` | 7 scenes run back to back and checked against the multilane model (`cmtz/isa/multicore.py`): every lane's registers, index registers, data memory, status, retired count, cycle count and stall cycles. Generated. |
| `cmtz_mlane_uart_tb.v` | 2 scenes over the UART pins, plus the protocol's refusals. Generated. |
| `pins.cst`, `apio.ini` | As cmtz-core; `-noalu` |

Regenerate with `examples/fpga/build_projects.py <dir> --mlane 4`.

## Status

Both testbenches pass in simulation and `apio build` succeeds. Checked on the board with `examples/fpga/mlane_run.py` (468 of 468 checks with --quick: the standard scenes, 7 program pairs, an interrupt on one lane while the others run; then 252 of 252 for a 12-job throughput batch). See `docs/cmtz-multilane.md` of this repo.

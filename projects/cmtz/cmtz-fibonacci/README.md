# cmtz-fibonacci

Compute F_12 mod 17 = 8 using a pure unrolled addition chain.

The datapath is generated by the Verilog backend of the Cook-Mertz compiler from `fibonacci_pure.cmtz`:

```
-- fibonacci_pure.cmtz
--
-- Compute F_12 mod 17 = 8 using a pure unrolled addition chain.
-- No matpow, no external matrix — the entire computation is expressed
-- in the DSL using embed + add.
--
-- Fibonacci recurrence: F_n = F_{n-1} + F_{n-2}
-- Seed: F_1 = 1, F_2 = 1  (both = ω^0 = 1 in F_17)
--
-- Sequence mod 17:
--   F1=1  F2=1  F3=2  F4=3  F5=5  F6=8  F7=13
--   F8=4  F9=0  F10=4  F11=4  F12=8

field(17, 19);

-- Seeds: both embed index 0 (F_1) and index 1 (F_2) are ω^0 = 1 mod 17
embed(0, 0);   -- embed_0 = F_1 = 1
embed(1, 0);   -- embed_1 = F_2 = 1

-- Unrolled Fibonacci: F_n = F_{n-1} + F_{n-2}
add(embed_0, embed_1) as F3;    -- 1 + 1 = 2
add(F3, embed_1) as F4;         -- 2 + 1 = 3
add(F4, F3) as F5;              -- 3 + 2 = 5
add(F5, F4) as F6;              -- 5 + 3 = 8
add(F6, F5) as F7;              -- 8 + 5 = 13
add(F7, F6) as F8;              -- 13 + 8 = 21 ≡ 4
add(F8, F7) as F9;              -- 4 + 13 = 17 ≡ 0
add(F9, F8) as F10;             -- 0 + 4 = 4
add(F10, F9) as F11;            -- 4 + 0 = 4
add(F11, F10) as F12;           -- 4 + 4 = 8

measure(F12, mod_p) as result;
```

The program's literal embeds are replaced by input ports, so the datapath computes the same graph for any values in 0 to 16 instead of the constants in the source. It has 10 pipeline stages, one result per clock, and no `%` operators: reductions are unrolled conditional subtracts.

## Ports

| Port | Bits | Carried as |
|---|---|---|
| `in_embed_0` | 5 | request byte 0 |
| `in_embed_1` | 5 | request byte 1 |
| `out_result` | 5 | reply byte 0 |

## UART protocol

115200 8N1 on the on-board USB bridge. Send 2 bytes (each 0 to 16), read 1 byte back. A complex port is two bytes, real part first. If any request byte is 17 or more, every reply byte is `0xFF`. If a request stalls partway for 250 ms, the bytes received so far are dropped. Bytes sent while a reply is going out are ignored, so read the whole reply before sending the next request.

Example: `00 03` replies `0C`.

LEDs (active low): `leds[4:0]` show the low bits of the first reply byte, `leds[5]` lights after an error reply.

## Files

| File | What |
|---|---|
| `cmtz_fibonacci_uart.v` | Top module `cmtz_fibonacci_uart`: UART receiver and transmitter and a control state machine around the datapath. Generated. |
| `cmtz_fibonacci.v` | The datapath. Generated. |
| `cmtz_fibonacci_tb.v` | Datapath testbench with 289 vectors, expected values from the compiler's Python reference. Generated. |
| `cmtz_fibonacci_uart_tb.v` | Whole-design testbench: bit-bangs the UART protocol for every vector, then checks the out-of-range reply and the resync timeout. Generated. |
| `pins.cst` | `clk` pin 4, `tx` pin 69, `rx` pin 70, LEDs pins 15 to 20 |
| `apio.ini` | Board and top module |

Regenerate with `examples/fpga/build_projects.py` in the Cook-Mertz repo rather than editing the generated files.

Both testbenches pass in simulation and `apio build` succeeds. Checked on the board over the UART (96 vectors, all matching).

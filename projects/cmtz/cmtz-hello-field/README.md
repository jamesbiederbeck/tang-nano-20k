# cmtz-hello-field

The simplest meaningful Cook-Mertz program.

The datapath is generated by the Verilog backend of the Cook-Mertz compiler from `01_hello_field.cmtz`:

```
-- 01_hello_field.cmtz
--
-- The simplest meaningful Cook-Mertz program.
-- Embeds two phase registers, sequences them, and reads both out.
--
-- Primitive root of F_17 is g=3, so:
--   ω^4  = 3^4  mod 17 = 81  mod 17 = 13
--   ω^8  = 3^8  mod 17 = 6561 mod 17 = 16   (= -1 mod 17: the "half-turn")
--   ω^16 = 1                                 (Fermat: g^(p-1) ≡ 1)

field(17, 19);           -- F_17, working field F_19 (smallest prime > 17)

roots(17) as omega17;    -- build ω-table: {3^j mod 17 : j ∈ [16]}

embed(0, 4);             -- register embed_0 ← ω^4 = 13
embed(1, 8);             -- register embed_1 ← ω^8 = 16

-- Sequence the two embeds so the cost model sees them as a single program.
-- Lemma 2.1: t(f∘g) = 1×1 = 1, s = 1 + 1 = 2, r = max(1,1) = 1
compose(embed_0, embed_1);

measure(embed_0, mod_p) as phi4;    -- expect 13
measure(embed_1, mod_p) as phi8;    -- expect 16  (= -1 mod 17)
```

The program's literal embeds are replaced by input ports, so the datapath computes the same graph for any values in 0 to 16 instead of the constants in the source. It has 1 pipeline stage, one result per clock, and no `%` operators: reductions are unrolled conditional subtracts.

## Ports

| Port | Bits | Carried as |
|---|---|---|
| `in_embed_0` | 5 | request byte 0 |
| `in_embed_1` | 5 | request byte 1 |
| `out_phi4` | 5 | reply byte 0 |
| `out_phi8` | 5 | reply byte 1 |

## UART protocol

115200 8N1 on the on-board USB bridge. Send 2 bytes (each 0 to 16), read 2 bytes back. A complex port is two bytes, real part first. If any request byte is 17 or more, every reply byte is `0xFF`. If a request stalls partway for 250 ms, the bytes received so far are dropped. Bytes sent while a reply is going out are ignored, so read the whole reply before sending the next request.

Example: `00 03` replies `00 03`.

LEDs (active low): `leds[4:0]` show the low bits of the first reply byte, `leds[5]` lights after an error reply.

## Files

| File | What |
|---|---|
| `cmtz_hello_field_uart.v` | Top module `cmtz_hello_field_uart`: UART receiver and transmitter and a control state machine around the datapath. Generated. |
| `cmtz_hello_field.v` | The datapath. Generated. |
| `cmtz_hello_field_tb.v` | Datapath testbench with 289 vectors, expected values from the compiler's Python reference. Generated. |
| `cmtz_hello_field_uart_tb.v` | Whole-design testbench: bit-bangs the UART protocol for every vector, then checks the out-of-range reply and the resync timeout. Generated. |
| `pins.cst` | `clk` pin 4, `tx` pin 69, `rx` pin 70, LEDs pins 15 to 20 |
| `apio.ini` | Board and top module |

Regenerate with `examples/fpga/build_projects.py` in the Cook-Mertz repo rather than editing the generated files.
